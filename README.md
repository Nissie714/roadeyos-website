# Road-e-yos website

The new website for **Road-e-yos Bootcamp & Fitness Centre**.

## Run the website

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a web browser.

## Useful checks

```bash
npm run lint
npm run build
```

## Project structure

- `src/app` — pages, global styling and site metadata
- `public` — images, icons and other static files

Built with Next.js, TypeScript and Tailwind CSS.
